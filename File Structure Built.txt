KEY TECHNICAL NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  - Single-file HTML app — no build system, no framework, no server needed
  - All JS modules are IIFEs (Immediately Invoked Function Expressions)
  - cesApplyDropdowns() converts all <select> to custom styled dropdowns
  - MutationObserver auto-applies dropdowns to dynamically rendered content
  - Custom CES Date/Time Picker (datetime-picker.js) — 3 modes
  - Chart.js loaded from CDN for any canvas-based charts
  - Data persists via localStorage (saveCESData runs every 1s + on page unload)
  - Phase 2: Google Sheets replaces localStorage as the data backend
  - Auto-refresh: __cesRender global map holds each panel's render function;
    60s countdown in topbar silently re-renders current panel every 60 seconds
  - Event types must exactly match filter dropdown option text (strict === comparison)
